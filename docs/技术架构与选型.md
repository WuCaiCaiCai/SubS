# 技术架构与选型

## 总体形态

单一 Go 静态二进制 `subs`，内嵌前端构建产物（`go:embed`）。VPS 上一条 `curl | bash` 命令完成安装，systemd 托管运行。所有数据落在 `/var/lib/subs/`，与程序、日志分离，便于备份与销毁。

```
浏览器 ──HTTPS──> [subs 二进制]
                   ├── /admin/*   管理界面（Session Cookie 认证）
                   ├── /api/*     管理 REST API（同认证）
                   └── /s/<token> 订阅分发（仅 token 授权，按 UA 协商格式）
                          ├── Mihomo   → Clash YAML
                          ├── sing-box → sing-box JSON outbounds
                          └── Loon     → Surge/Loon 风格 conf
```

## 技术栈（锁定）

| 层 | 选型 | 理由 |
|---|---|---|
| 后端 | Go 1.22+，仅标准库 + 少量必要三方库 | 交叉编译单文件，无运行时依赖 |
| Web 框架 | `github.com/go-chi/chi/v5` | 轻量路由 + 中间件链，无额外依赖 |
| 数据库 | SQLite via `modernc.org/sqlite`（纯 Go，无 cgo） | 交叉编译不被 cgo 破坏 |
| 前端 | Vite + React 18 + TS strict + Tailwind + shadcn/ui + lucide-react | 见前端设计规范 |
| 动效 | motion（仅 Reorder 排序与列表入场） | 克制动效 |
| YAML/JSON | `gopkg.in/yaml.v3`、标准 `encoding/json` | 模板解析与 sing-box 输出 |
| 二维码 | `github.com/skip2/go-qrcode`（后端生成 PNG，或前端用 `qrcode` npm 包，统一用前端方案，embed 二进制无需新增 Go 库） | 发布页扫码导入客户端 |
| 虚拟滚动 | `@tanstack/react-virtual`（前端，仅节点库列表） | 50+ 节点列表性能 |
| 密码哈希 | `golang.org/x/crypto/argon2id` | |
| 静态加密 | `x/crypto/nacl/secretbox`（应用密钥派生） | 秘密字段加密存储 |

## 后端模块划分

```
internal/
├── server/      # HTTP 路由、中间件（认证、CSRF、限流、日志脱敏）
├── store/       # SQLite 访问层、迁移、并发写互斥（单写队列）
├── airport/     # 机场订阅拉取（超时/大小/重试/SSRF 校验）、解析、节点指纹合并
├── node/        # 自建节点 CRUD、URI 导入解析
├── profile/     # 编排、排序、命名规则求值、节点选择集
├── render/      # 按 UA 协商输出 Mihomo/sing-box/Loon；模板合成与校验
├── backup/      # 加密备份导出/导入、校验和
├── destroy/     # 销毁流程（需确认短语 + 备份核对）
└── secrets/     # Secret 类型、应用密钥管理
```

## 关键运行机制

- **订阅按请求合成**：`/s/<token>` 每次请求由当前数据实时生成（可加 60s 内存 TTL 缓存），无后台定时生成。
- **单写者模型**：所有写操作经 store 层一把互斥锁串行化，读走 WAL 并发。备份导出期间暂停写。
- **原子写入**：配置/数据库迁移用 `write temp + rename`。
- **首次初始化**：无账号时访问管理路径进入初始化页面；初始化密钥由安装脚本生成，只输出到安装终端并以 0600 权限保存，不能写入 journal。
- **密码重置**：仅 `subs reset-password` 本地命令。

## 字体打包策略

- Geist Sans / Geist Mono：从 `npm install geist` 获取 woff2 文件，构建时 Vite 将 `node_modules/geist/dist/fonts/*.woff2` 复制到 `web/dist/fonts/`，CSS `@font-face` 引用相对路径，整体随 `go:embed` 进二进制。
- 生产环境**不依赖 Google Fonts**，纯离线可用。
- 备选（若 geist npm 包结构变化）：`fontsource` 系列包，策略相同。

## 备份文件格式（.sbox）

`.sbox` = age 加密的 tar.gz 包，内部结构：

```
subs-backup/
  metadata.json   # 版本、实例名、导出时间、表行数统计
  db.sqlite       # WAL checkpoint 后的 SQLite 文件完整拷贝
```

加密：用户输入密码 → `age` scrypt passphrase 加密（`filippo.io/age` 库）。解密即恢复：age 解密 → tar 解压 → 校验 metadata.json 版本 → 以 db.sqlite 替换当前库（原库先快照）。无密码保护时 metadata.json 中 `encrypted: false`，直接 tar.gz。

## 前后端协作

- 前端 `/web`，构建产物 `web/dist` embed；开发期 Vite proxy 到 `:8787`。
- API 契约见 `数据模型与API规范.md`，前后端都以此为准，改动需同 commit 更新。
- 无 SSR、无 i18n 框架，界面文案中文硬编码。

## Session 存储

- Session 存 SQLite `admin_session` 表（见数据模型），`id` 为 32 字节随机 base62，Cookie `HttpOnly; SameSite=Lax; Path=/`，过期 24h。
- `subs reset-password` 执行时 `DELETE FROM admin_session`，使全部在线会话立即失效。
- 内存不缓存 session，每次请求查库，WAL 读无锁。

## 安全基线（实现必须遵守）

- 管理路由：Session Cookie（HttpOnly、SameSite=Lax）+ CSRF token；登录限速。
- 订阅路由：token 为 32 字节随机 base62；`Cache-Control: private, no-store`。
- 日志中间件统一脱敏：不落 token、订阅 URL、节点凭据、请求体。
- 默认监听 `0.0.0.0:8787`（安装器交互可改为 `127.0.0.1:8787`）；运维人员可通过 `--listen` / `SUBS_LISTEN` 配置，不在 Web 界面修改。
