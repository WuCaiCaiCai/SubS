# 前端设计规范（完整版）

> 配套《设计说明.md》《数据模型与API规范.md》的界面规范。设计系统参考 ui-ux-pro-max 检索结果（dark ops / data-dense 风格）并按本项目单用户运维面板场景裁剪。AI 实现界面时以本文为唯一视觉与交互依据，不得自由发挥。

## 0. 设计立场

**Terminal Ops**：单用户、自托管、暗色优先的运维面板。对标 Vercel/Railway 的气质——安静、紧凑、层级分明。差异化来自**密度控制、等宽排版的语言、机场与 VPS 的双色区分系统**，而不是视觉冲击。

三条铁律：

1. 技术字符串（节点名、端口、token、YAML）是界面的主角，永远等宽字体。
2. 机场与 VPS 是平级但**性质不同**的两种来源，必须一眼可辨，不许只靠文字。
3. 所有危险动作（销毁、轮换、删除）的视觉重量必须与后果重量匹配。

## 1. 技术栈

- Vite + React 18 + TypeScript strict + Tailwind CSS + shadcn/ui + lucide-react
- 动效：CSS transition 为主；拖拽排序用 motion 的 `Reorder`
- 全站图标 lucide-react，16/20px，stroke 1.5，**无 emoji**
- 路由：react-router；数据：fetch + SWR 模式（手写轻量 hook 亦可）

## 2. 主题与色彩

暗色默认，可切浅色或跟随系统（侧栏底部按钮循环，设置页三选一）。用户在 `localStorage` 的 `subs-theme` 存偏好，`index.html` 内联脚本在样式表加载前写入 `data-theme`，避免首屏闪白/闪黑。

全部走两级 CSS 变量：`@theme` 里 `--color-*: var(--c-*)` 生成 Tailwind 工具类，`[data-theme="light"]` 只重写 `--c-*`。组件内**禁止裸 hex 与具体色阶**（`text-zinc-500`、`bg-cyan-400` 之类），一律用语义类名。

| 语义类 | 令牌 | 暗色 | 浅色 | 用途 |
|---|---|---|---|---|
| `bg-canvas` | `--c-canvas` | `oklch(0.145)` | `oklch(0.968)` | 页面底、输入框底 |
| `bg-surface` | `--c-surface` | `oklch(0.196)` | `#fff` | 卡片、弹层 |
| `bg-raised` | `--c-raised` | `oklch(0.256)` | `oklch(0.955)` | hover、选中、标签底 |
| `border-line` | `--c-line` | `oklch(0.303)` | `oklch(0.905)` | 1px 细边框 |
| `border-line-strong` | `--c-line-strong` | `oklch(0.395)` | `oklch(0.827)` | hover 边框、分隔强调 |
| `text-fg` | `--c-fg` | `oklch(0.976)` | `oklch(0.205)` | 标题、主值 |
| `text-fg-soft` | `--c-fg-soft` | `oklch(0.874)` | `oklch(0.365)` | 表格单元格、正文强调 |
| `text-fg-muted` | `--c-fg-muted` | `oklch(0.732)` | `oklch(0.48)` | 说明文字、标签 |
| `text-fg-subtle` | `--c-fg-subtle` | `oklch(0.596)` | `oklch(0.542)` | 单位、占位符、极次要信息 |
| `text-accent` / `bg-accent` | `--c-accent` | 青 | 深青 | 可交互/选中/链接 |
| `text-warning` | `--c-warning` | 琥珀 | 深琥珀 | 新增/缺失节点、跳过提示 |
| `text-success` | `--c-success` | 绿 | 深绿 | 正常、校验通过 |
| `text-danger` | `--c-danger` | 红 | 深红 | 错误、销毁 |
| `--airport-accent` / `--server-accent` | 同左 | 浅蓝 / 浅橙 | 深蓝 / 深橙 | 机场 / VPS 标识点 |

对比度实测（脚本按 WCAG 公式算可得）：正文 ≥16:1，次要 ≥6.5:1，极次要 ≥4.4:1，语义色 ≥5.7:1，两套主题都过 AA；调色板改动后必须重新量一遍。

### 双色区分系统（本规范的核心机制）

机场与 VPS 在全站所有出现处统一用两个标识维度区分，二者叠加：

1. **色条/色点**：来源行、来源树、节点标签左侧 3px 圆角竖条或 6px 圆点——机场 sky、VPS orange。
2. **图标**：机场 = `Plane`；VPS = `Server`。协议用文字徽章（`HY2`/`VLESS`/`TUIC`/`ANYTLS`/`MIERU`，等宽小字+边框），不用彩色图标。

色盲安全：双色系统永远伴随图标/文字，不构成仅靠颜色的区分。在浅色和深色下分别验证对比度。

## 3. 字体与排版

根字号 `html { font-size: 18px }`，所有字号用 rem 表达，改根字号即整体等比放大（当前基线针对老花眼上调过一档：正文约 14.6px）。

| 令牌 | 实际尺寸 | 用途 |
|---|---|---|
| `text-meta` | 12.4px | 徽章、单位、路径、列标题 |
| `text-body` | 14.6px | 正文默认（`body`） |
| `text-strong` | 15.8px | 列表主值、表格单元格、按钮与输入框 |
| `text-title` | 18px | 卡片标题 |
| `text-subhead` | 20px | 区块小标题 |
| `text-page` | 27px | 页面主标题 |
| `text-metric` | 36px | 指标数字 |

层级靠**字号 + 颜色两轴**拉开，同一张卡片内最多三级：

1. **主值**：`text-strong` + `text-fg`，必要时 `font-medium`；
2. **说明**：`text-body`/`text-meta` + `text-fg-muted`；
3. **辅助**：`text-meta` + `text-fg-subtle`（`label-xs` 全大写 tracking 或 `.meta`）。

代码类内容用 Geist Mono，字号取上下文的 0.95em；长 token/URL 一律 `break-all` 或 `truncate` + 复制按钮，卡片内不出现横向滚动条（代码编辑器自身滚动除外）。

## 4. 布局与自适应

**移动优先实现**（Tailwind 默认样式即移动样式，`md:`/`lg:` 增强）：

- **<768px（手机）**：底部 Tab 导航（总览/来源/编排/设置，4 项带图标+文字，≥44px 高，`pb-[env(safe-area-inset-bottom)]`）；列表变卡片流；侧栏来源树折叠为顶部横向筛选 chips；操作收进行尾 `MoreHorizontal` 菜单（点开 ≥44px 菜单项）；拖拽排序在触屏用上/下移动按钮替代；模板编辑器用等宽 textarea + 等宽字号 14px（防 iOS 聚焦自动放大）。
- **≥768px（平板）**：底部 Tab → 左侧图标窄栏。
- **≥1024px（桌面）**：完整侧栏（图标+文字，当前项 cyan 左边条+高亮）；内容 `max-w-6xl`；两栏页面（来源树+节点表）生效。

通用：`min-h-dvh`（不用 100vh）、禁止横向滚动、固定栏下内容留 padding、`overscroll-behavior: contain` 防误触下拉刷新、触摸目标 ≥44px 且间距 ≥8px、`touch-action: manipulation`。

间距系统 4/8 尺度：区块间 24/32px，卡片内 16px，行内 8px。

## 5. 逐页界面设计

### 5.1 登录 / 首次初始化

单卡片居中（`max-w-sm`）：产品名等宽字体 + 一句副标题（"自托管订阅管理"）。输入框 44px 高、可见 label、密码显隐切换。错误信息红色置于字段下方并 `role="alert"`。登录失败 5 次提示限速剩余时间。首次初始化设置管理员账号与密码；服务监听使用运维启动参数，不在网页向导中设置。

### 5.2 总览（Dashboard）

不做花哨图表。Bento 式紧凑卡片网格（桌面 2 列，移动 1 列）：

- **状态条**：服务运行、版本、磁盘占用
- **来源卡 ×2**：机场数/VPS 数 + 各自 accent 色条 + 最近刷新状态（含"3 个新节点待确认"amber 提示，点击直达）
- **订阅卡**：各 profile 一行（名称、节点数、启用开关、复制链接按钮），底部"新建编排"
- **备份提醒卡**：距上次备份 >30 天时 amber 提示

每卡片右上角 `ArrowUpRight` 跳转对应页。

### 5.3 来源管理（机场 & VPS）

顶部分段控件（Segmented）：`机场 (6) | VPS (3)`——两个平级入口，各用 accent 色。列表行结构：

```
[色条] Plane 图标 | 名称(等宽可选) | 节点数徽章 | 状态(最近刷新/错误) | [刷新/编辑/⋯]
```

- 机场行：名称 + 节点数 + `XX 分钟前更新`（相对时间，悬浮显绝对时间）或红色错误摘要；操作含"刷新"（spinner→结果 diff toast：`+2 新增 · 1 匹配 · 1 缺失`）
- VPS 行：名称 + 地址(等宽) + 节点数；操作"添加节点 / 编辑 / ⋯"
- 空状态：居中 `Plane`/`Server` 线框图标 + "还没有机场订阅" + primary 按钮"添加第一个机场"

新增机场表单：URL 字段输入时即提示"此地址含凭据，将加密存储"（`Lock` 图标 helper 文字）；粘贴后"拉取预览"按钮展示解析统计再保存。所有表单：可见 label、blur 时行内校验、提交 loading 态、错误定位到字段。

### 5.4 节点库

桌面两栏：左侧来源树（机场组/VPS 组平级，组头带图标+accent 色，可折叠，多选勾选组=全选该组）；右侧节点表。移动端来源树折叠为筛选 chips + 协议下拉 + 搜索框（sticky 顶栏）。

节点行：`[来源色点] 输出名(等宽) | 协议徽章 | host:port(等宽,muted) | 状态 | ⋯`

状态三态徽章（图标+文字，不只靠色）：`新` (amber, Sparkles→确认后消失)、`缺失` (muted+删除线, 复原操作在 ⋯ 菜单)、`停用` (muted 开关)。批量操作栏：选中 N 项时从底部滑出（移动端）/ 表头上方（桌面），含停用/启用/删除/加入编排。

50+ 节点列表虚拟化滚动（如 `@tanstack/react-virtual`）。

导入（自建节点）：对话框选 VPS 归属 → 粘贴多行 URI → 解析预览表（成功行绿色勾、失败行红色+原因）→ 确认导入，失败行保留文本可修正重试。敏感字段输入一律 `type=password` + 显隐切换 + 常驻复制按钮，值显示 `••••••`。

### 5.5 订阅编排（核心页）

三步式编辑器（顶部步骤条：选节点 → 排序命名 → 模板发布，可自由跳回，移动端占满顶栏）：

**步骤一·选择**：来源树（同 5.4）勾选，右侧已选列表实时汇总，顶部计数 `已选 12 个节点 · 来自 3 个来源`。

**步骤二·排序与命名**：

- 已选节点列表，每行左侧拖把手（`GripVertical`，桌面拖拽 motion Reorder；移动端行尾 ↑↓ 按钮替代，键盘用户同样用 ↑↓）
- 命名规则编辑器：段列表 UI（可增删排序"变量胶囊"如 `[序号] [来源] [协议] [原名]`）+ 分隔符选择 + **实时预览列**显示每行最终名；重名行 amber 高亮并显示自动 `-2` 后缀；单行可点铅笔覆盖名称
- 预览列与规则编辑并排（桌面），移动端上下排

**步骤三·模板与发布**：模板下拉（校验状态绿勾/红叹号）+ 目标客户端选择（Mihomo/sing-box/Loon 徽章）+ **渲染预览**（等宽、语法高亮 YAML/JSON、只读滚动区）→ 发布按钮。

发布成功 = **全站唯一的高光时刻**：链接卡片展开动画、复制按钮变 `Check` 绿色、toast "订阅已就绪"。链接文本等宽 + 一键复制 + 二维码（移动端扫码导入客户端，qrcode 库本地生成）。含 Mieru 节点而目标选了 sing-box/Loon 时，预览头部 warning 条："2 个 Mieru 节点将被跳过（该客户端不支持）"。

Profile 列表页：名称、节点数、模板名、启用开关、`最后拉取 xx 前`，操作含轮换 token（确认对话框说明旧链接立即失效）。

### 5.6 模板管理

列表 + 编辑对话框（桌面大 Modal，移动端全屏 Sheet）。编辑器：等宽 textarea + 行号 + 保存时校验结果（错误列表点击跳行）+ subs 占位符语法速查折叠面板 + 示例模板一键填充。校验通过显示绿色状态与时间。

### 5.7 备份与迁移

单卡片流程页：

1. "创建备份"（设置备份密码，强度提示）→ 生成中进度 → 完成显示 sha256（等宽、可复制）+ 下载按钮
2. 恢复：文件选择 + 密码 + 校验和核对 → 预览包内统计（几个机场/节点/编排）→ 确认恢复（红色确认：将覆盖当前数据）
3. 下载一次性链接 10 分钟过期倒计时

### 5.8 销毁（设计重量最高的页面）

独立全屏页面（不是 Modal，防止误触）。三段式：

1. **边界声明**：清单式列出将删除什么/不会删除什么（VPS 不退订、云快照不清理、本地文件不管）——复选框逐条确认
2. **备份核对**：必须粘贴已下载备份的 sha256，与服务器最近备份记录比对，不匹配红色报错；或勾选"我确认不需要任何备份"（再走一道确认短语）
3. **最终确认**：输入实例名确认短语 → 红色销毁按钮（输入正确前 disabled，进度条走完显示终止页："实例已销毁。最终备份保留于 /var/lib/subs/final-backup.sbox"）

### 5.9 设置

分组卡片：实例标识、订阅链接基础 URL、管理员认证（改密码）、外观（深浅色/跟随系统）、安全状态、版本与升级。服务监听地址属于运维配置，不在页面提供修改项。

## 6. 全局组件状态规范

- **按钮**：每屏一个 primary；hover 边框提亮 120ms；active 轻微 `scale[0.98]`；disabled opacity-50 + cursor-not-allowed + 语义属性；async 期间 disabled+spinner 替换文字左侧；danger 按钮红色边框、与 primary 空间分离
- **表单**：可见 label（不用 placeholder 当 label）；blur 校验；错误在字段下方 + `aria-live`；多错误时首个无效字段自动聚焦；长表单自动保存草稿；关闭含未保存内容的弹层需确认
- **Toast**：右上（移动端顶部居中），3–5s 自动消失，成功绿边/错误红边/警告 amber 边，`aria-live="polite"`，可手动关
- **删除**：一律确认对话框；批量删除提供 5s 撤销 toast（本地恢复）
- **加载**：>300ms 显示骨架屏（列表用骨架行，不用转圈占满）；按钮内 spinner
- **空态**：图标+一句话+一个 primary 动作，每类列表分别设计文案

## 7. 动效规范

原则：微交互 120–200ms、入场 stagger 30ms/item 一次性、`prefers-reduced-motion` 下全部静止（骨架屏与即时状态切换替代）。

| 场景 | 动效 |
|---|---|
| 页面加载 | 列表项淡入+上移 4px，stagger 30ms，150ms |
| 卡片/行 hover | 边框 zinc-800→700 + 背景微亮，120ms |
| 拖拽排序 | Reorder，拖起 scale 1.02 + 阴影 |
| 危险确认区 | 渐显展开 200ms（全站唯一"重"动效） |
| 新节点徽章 | 一次性 pulse |
| 发布订阅 | 链接卡片展开 + 复制变 ✓ + toast（流程终点高光时刻） |
| Tab/路由切换 | 仅内容淡入 120ms，无滑动转场 |

明确禁止：滚动视差、渐变扫光、hero 动画、大面积 transform、卡片随滚动浮现、>500ms 动效、装饰性光晕。

## 8. 无障碍验收线

- 全部文字对比 ≥4.5:1（两种主题分别测，尤其 zinc-400 on zinc-900）
- focus-visible 一律可见 ring，不被 sticky 头遮挡；Tab 顺序=视觉顺序
- 拖拽有键盘替代；状态不只靠颜色（徽章带文字）
- 图标按钮全部 aria-label；跳过链接到主内容
- 支持系统字号放大不破版（用 rem、不写死高度容器）
